# Food Truck Manager

A Java programming project developed as part of my coursework at La Trobe University. The project explores object-oriented programming, file handling, user input, and basic application logic through food truck management tasks.

## Technologies

- Java

## Features

- Read food truck records from a text file and search by cuisine.
- Simulate customer orders and compare revenue against a target.
- Manage food trucks across zones using a menu-driven interface.
- Assign trucks to zones and update truck ratings.
- Validate user input, including rating ranges and duplicate identifiers.

## Project Structure

The coursework includes several Java programs, including:

- `TruckLookup.java` — loads and searches food truck data.
- `ShiftSimulator.java` — simulates orders and calculates revenue.
- `RallyManager.java` — provides a menu for managing zones and trucks.
- `Zone.java` — manages trucks within a zone.
- `truck.java` — represents a food truck and its details.

## How to Run

1. Install a Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project folder in a terminal or Java IDE.
4. Compile and run the relevant program. For example:

   ```bash
   javac *.java
   java RallyManager
   ```

   Other programs, such as `TruckLookup` and `ShiftSimulator`, can be run separately. If using the lookup program, keep the required input text file available and enter its filename when prompted.

> Note: The commands above assume the source files compile together and use the indicated class names. Adjust them to match the final files in the repository.
